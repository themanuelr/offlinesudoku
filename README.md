# Offline Sudoku

An installable Sudoku that works fully offline, hosted on GitHub Pages.

## Develop

```sh
npm install
npm run dev      # local dev server
npm test         # unit tests
npm run build    # production build in dist/
npm run e2e      # end-to-end tests (phone and tablet sizes, offline)
```

The version shown in settings comes from `package.json` (`0.1.0` shows as `v0.1`).
